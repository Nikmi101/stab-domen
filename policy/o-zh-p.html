2. Какие данные обрабатываются

Приложение не требует создания учётной записи и не предусматривает отправку обращений на собственный сервер для их хранения.

В зависимости от выбранного способа связи Оператор может получать от пользователя следующие данные:

  • имя, псевдоним или иное обозначение, если пользователь указывает его самостоятельно;
  • адрес электронной почты, имя пользователя, номер телефона или другой идентификатор, доступный в выбранном канале связи;
  • текст обращения, вопроса или описания жизненной ситуации;
  • сведения, которые пользователь добровольно включает в обращение;
  • содержание переписки, необходимое для подготовки и отправки ответа.

Пользователь самостоятельно определяет, какие сведения сообщать Оператору. Не следует включать в обращение избыточные персональные данные — свои или других людей, — если они не нужны для рассмотрения ситуации.

В Приложении не предусмотрены отдельная регистрационная база пользователей, собственная база обращений и встроенная система оплаты банковскими картами.

3. Цели обработки персональных данных

Оператор обрабатывает полученные данные только в объёме, необходимом для следующих целей:

  1. Получение и рассмотрение обращения пользователя.
  2. Подготовка и отправка индивидуального письменного ответа.
  3. Связь с пользователем по поводу его обращения.
  4. Исполнение обязательств, возникающих в связи с обращением или оказанием услуги.
  5. Рассмотрение запросов пользователя о его персональных данных.
  6. Выполнение обязанностей, предусмотренных законодательством Российской Федерации.

Оператор не использует содержание обращений для рекламных рассылок, продажи баз данных или автоматизированного профилирования пользователей.

Оператор не передаёт содержание обращений третьим лицам для публикации или использования в рекламных целях.

4. Как передаются обращения

Для связи с Оператором Приложение может открывать внешнее приложение электронной почты или выбранный пользователем мессенджер, а также предоставлять возможность скопировать текст обращения в буфер обмена устройства.

В зависимости от доступных пользователю способов связи могут использоваться:

  • электронная почта Mail.ru;
  • Telegram;
  • ВКонтакте;
  • MAX.

Перечень доступных способов связи определяется текущей версией Приложения.

При использовании внешнего сервиса пользователь самостоятельно отправляет подготовленное обращение. До отправки он может просмотреть и изменить его текст.

После отправки сообщения его обработка осуществляется также соответствующим почтовым сервисом или мессенджером на условиях и в соответствии с политикой конфиденциальности этого сервиса.

Оператор не управляет внутренними системами хранения, резервного копирования и обработки данных сторонних сервисов и не может определять сроки хранения данных этими сервисами.

Если пользователь использует функцию копирования, текст обращения помещается в буфер обмена устройства. Дальнейшее использование этого текста зависит от действий пользователя, операционной системы и используемых приложений.

5. Правовые основания обработки

Оператор обрабатывает персональные данные на основаниях, предусмотренных законодательством Российской Федерации, в частности:

  • для заключения договора по инициативе пользователя и исполнения договора, стороной которого является пользователь, когда это применимо;
  • с согласия пользователя — в случаях, когда такое согласие необходимо по закону;
  • для исполнения обязанностей, возложенных на Оператора законодательством Российской Федерации.

Направляя обращение, пользователь добровольно сообщает сведения, необходимые для рассмотрения его запроса. Сам факт отправки сообщения не заменяет отдельного согласия в тех случаях, когда законодательство требует получить такое согласие в установленной форме.

Пользователь должен направлять Оператору только те персональные данные третьих лиц, которые необходимы для описания ситуации и в отношении которых у пользователя имеются законные основания для передачи.

6. Хранение и удаление данных

Оператор не ведёт отдельную базу данных пользователей и не создаёт в Приложении архив обращений.

Обращения обрабатываются в том внешнем сервисе связи, который пользователь выбрал для отправки сообщения. Переписка может сохраняться в соответствующей учётной записи Оператора и пользователя в соответствии с возможностями и правилами этого сервиса.

Оператор не устанавливает сроки хранения данных внутри сторонних сервисов и не может гарантировать удаление всех копий сообщений из их систем, включая резервные копии.

Данные, находящиеся под непосредственным контролем Оператора, не должны храниться дольше, чем это необходимо для целей обработки, если более длительное хранение не требуется законодательством Российской Федерации.

Пользователь вправе обратиться к Оператору с запросом об удалении данных, находящихся под непосредственным контролем Оператора. Такой запрос рассматривается с учётом действующего законодательства и необходимости сохранить сведения, которые Оператор обязан хранить по закону.

Для удаления переписки из почтового ящика или мессенджера пользователь при необходимости должен воспользоваться средствами соответствующего сервиса.

7. Передача данных третьим лицам

Оператор не продаёт персональные данные пользователей и не передаёт содержание обращений третьим лицам для самостоятельного использования в коммерческих или рекламных целях.

Передача данных внешнему сервису связи происходит в связи с выбранным пользователем способом отправки обращения. При этом соответствующий сервис самостоятельно обрабатывает данные в соответствии со своими правилами.

Оператор также вправе предоставить данные в случаях, когда такая передача требуется законодательством Российской Федерации или законным требованием уполномоченного государственного органа.

Использование отдельных сервисов связи может сопровождаться обработкой данных за пределами Российской Федерации. Порядок такой обработки определяется применимым законодательством и условиями соответствующего сервиса.

8. Защита персональных данных

Оператор принимает разумные организационные меры для защиты полученных обращений от неправомерного доступа, раскрытия, изменения или уничтожения.

Оператор не публикует обращения пользователей и не раскрывает их содержание другим лицам по собственной инициативе, за исключением случаев, предусмотренных законодательством Российской Федерации.

Пользователю рекомендуется не направлять пароли, платёжные данные, копии документов и другие сведения, которые не нужны для рассмотрения обращения.
